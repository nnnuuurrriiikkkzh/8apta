# JobHub — три страницы UI

Учебный интерфейс поиска работы на Next.js 16, React 19, TypeScript и Tailwind CSS 4. Компании и вакансии вымышлены. База данных, авторизация и отправка откликов не подключены.

## Запуск

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000. Если этот порт занят, используйте `npm run dev -- --port 3001`.

```bash
npm run build
npm start
```

Команды используют Webpack и стандартный плагин `@tailwindcss/postcss`: в текущей среде Windows Turbopack завершался внутренней ошибкой запуска процесса обработки CSS.

## Страницы

- `/` — главная: поиск, направления, подборка вакансий, описание шагов.
- `/jobs` — каталог: поиск по должности, компании, направлению и навыкам; фильтры по городу, формату, опыту и зарплате; сортировка и пагинация.
- `/jobs/product-designer` — пример страницы вакансии. Остальные карточки открывают тот же шаблон со своими данными по `/jobs/[id]`.

Избранное сохраняется в localStorage браузера и доступно через `/jobs?saved=true`. Фильтры записываются в URL. Форма отклика проверяет обязательные поля и показывает демонстрационное подтверждение без передачи и сохранения введённых данных.

## Структура

- `app/` — страницы, метаданные и общие стили.
- `components/` — шапка, подвал, карточки, поиск, фильтры, избранное и форма отклика.
- `lib/jobs.ts` — восемь демонстрационных вакансий.
- `TZ.md` — исходное ТЗ всей платформы; текущая реализация ограничена тремя UI-страницами.

Интерфейс адаптируется под мобильные и настольные экраны. Предусмотрены мобильное меню, сворачиваемые фильтры, пустая выдача и страница для неизвестной вакансии.
