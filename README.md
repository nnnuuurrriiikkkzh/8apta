# JobHub — интерфейс поиска работы и заявок

Учебный интерфейс поиска работы на Next.js 16, React 19, TypeScript и Tailwind CSS 4. Компании и вакансии вымышлены. База данных, авторизация и отправка откликов не подключены.

## Запуск

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000. Если этот порт занят, используйте `npm run dev -- --port 3001`.

Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd run dev` (и аналогично `npm.cmd ci`, `npm.cmd run build`).

```bash
npm run build
npm start
```

Команды используют Webpack и стандартный плагин `@tailwindcss/postcss`: в текущей среде Windows Turbopack завершался внутренней ошибкой запуска процесса обработки CSS.

## Страницы

- `/` — главная: поиск, направления, подборка вакансий, описание шагов.
- `/jobs` — каталог: поиск по должности, компании, направлению и навыкам; фильтры по городу, формату, опыту и зарплате; сортировка и пагинация.
- `/jobs/product-designer` — пример страницы вакансии. Остальные карточки открывают тот же шаблон со своими данными по `/jobs/[id]`.
- `/dashboard/employer/applications` — демонстрационный список заявок работодателя: поиск кандидатов, фильтры по вакансии и статусу, просмотр резюме и сопроводительного письма, изменение статуса. Доступен через ссылку «Работодателю» в меню.
- `/login` — UI входа: email, пароль, переключение видимости пароля, проверка полей и демонстрационный результат.
- `/register` — UI регистрации: выбор соискателя или работодателя, имя, email, пароль и его подтверждение.
- `/forgot-password` — UI восстановления: проверка email, демонстрационное подтверждение запроса и возможность указать другой адрес.

### Этап 1 — UI авторизации

Формы входа, регистрации и восстановления связаны ссылками и доступны через кнопку «Войти» в шапке или мобильное меню. Есть состояния ошибок, ожидания и успеха. Введённые значения не отправляются на сервер; пароль не записывается в localStorage или sessionStorage и очищается после демонстрационного успеха. Реальные аккаунты, сессии, проверка существующего пользователя и отправка писем пока не реализованы. Для проверки можно использовать `demo@example.com` и любой тестовый пароль от 8 символов.

Избранное сохраняется в localStorage браузера и доступно через `/jobs?saved=true`. Фильтры записываются в URL. Форма отклика проверяет обязательные поля и показывает демонстрационное подтверждение без передачи и сохранения введённых данных.

Панель фильтров каталога можно скрыть и раскрыть на любом экране. При скрытии результаты занимают всю доступную ширину. В кабинете работодателя показаны шесть вымышленных заявок на вакансии компании «Линия». Их статусы сохраняются в localStorage, отозванные заявки нельзя изменять. Кабинет не связан с демонстрационной формой отклика; серверная авторизация и отправка уведомлений отсутствуют.

## Структура

- `app/` — страницы, метаданные и общие стили.
- `components/` — шапка, подвал, карточки, поиск, фильтры, избранное и форма отклика.
- `lib/jobs.ts` — восемь демонстрационных вакансий.
- `lib/applications.ts` — шесть демонстрационных заявок кандидатов.
- `app/(auth)/` и `components/auth/` — страницы и формы первого этапа UI авторизации.
- `TZ.md` — исходное ТЗ всей платформы; текущая реализация включает семь основных UI-страниц.

Интерфейс адаптируется под мобильные и настольные экраны. Предусмотрены мобильное меню, сворачиваемые фильтры, пустая выдача и страница для неизвестной вакансии.
